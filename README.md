# RHEVIX — Intelligence, Engineered for What's Next

A premium, production-quality homepage for **RHEVIX**, built as a self-contained single-file digital experience with Neo-Industrial Digital Luxury aesthetics.

## Overview
RHEVIX specializes in Artificial Intelligence, Autonomous AI Agents, Data Engineering, Software Engineering, Business Intelligence, and Cloud Solutions.

## Key Features
- **Interactive 3D Intelligence Core**: Built with Three.js featuring dynamic lattice particles, central crystalline octahedron, and pointer reactivity.
- **4 Modular 3D Capabilities**: AI (neural crystal sphere), Data (streaming lattice), Software (isometric architecture cubes), and Cloud (orbital rings).
- **Interactive Methodology**: "From Signal to Solution" step-by-step pipeline visualizer.
- **Demonstration Lab Showcase**: Interactive UI miniatures for RAG Assistant, Real-time Streaming Lakehouse, and Temporal Workflow graphs.
- **Architectural Estimator**: Interactive "What Could We Build for You?" challenge evaluator.
- **Principles & Rigor**: Enterprise security, reliability, human-centered AI, and continuous improvement pillars.
- **Interactive Consultation Dialog**: High-fidelity project scoping modal with instant parameter feedback.

## Tech Stack
- HTML5 / Vanilla CSS3 (Neo-Industrial Design System)
- JavaScript (ES6+)
- [Three.js](https://threejs.org/) (r128)
- [GSAP & ScrollTrigger](https://greensock.com/gsap/) (v3.12.5)
- [Lucide Icons](https://lucide.dev/)
- Typography: Space Grotesk, Inter, JetBrains Mono

## Running Locally
No build step or npm dependencies required. Simply open `index.html` in any modern web browser or serve via:

```bash
# Using Python
python -m http.server 3000

# Or using Node.js / npx
npx serve .
```
