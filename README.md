# rhevix.com homepage, Spectrum UI iteration

Next.js 16 + Tailwind v4 + Spectrum UI components (Apache 2.0, copied into components/spectrumui and components/ui and restyled).

Spectrum components used:
- Text States: hero word swap (components/Hero.tsx)
- Metal Button, gold preset: primary CTAs (WebGL liquid-metal ring via metal-fx)
- Tilt Card: illustrative programme view in the hero
- Beam Card, gold palette: Reason / Evolution / Execution
- FAQ Tabs Card: procurement questions
- Floating Label Input + Morph Button: briefing form

Rhevix edits to Spectrum source are marked in comments (e.g. Metal Button hydration fix).

npm install && npm run dev
